# 面试讲述要点

## 一句话

我把短视频生成拆成脚本、分镜、素材、配音、字幕和合成几个阶段，重点解决 AIGC 链路容易失败、需要局部重试和中间结果可编辑的问题。

## 核心设计

- 分阶段工作流：每一步有明确状态，失败后可以保留半成品。
- Provider 抽象：文案、图片、配音、视频阶段可接不同模型，并支持降级。
- 本地优先：Electron/Express/Vue 组合适合桌面演示和本地素材处理。
- 资产闭环：分镜、图片、音频、字幕、视频合成结果都有结构化记录。

## 可以展开的问题

- 为什么不做“一键黑盒生成”，而是拆分阶段？
- 图片或配音失败后如何保证项目不直接报废？
- FFmpeg 路径、上传目录、数据库和桌面打包分别怎么处理？
- 如果要商业化，任务队列、并发、鉴权、素材版权如何补？
