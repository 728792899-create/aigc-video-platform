# Demo Mode 演示脚本（约 5 分钟）

1. 启动前执行 `npm run test:demo`，说明它刚刚在临时目录真实验证了有效 MP4、单阶段重试和服务重启恢复，而且环境中没有模型 Key。
2. 执行 `npm run demo`，打开 `http://127.0.0.1:5173`。展示左侧步骤导航、主创作区和后台任务浮层。
3. 输入主题“用十秒解释可恢复的 AI 视频工作流”，启动一键成片。指出 Provider 标签为 Demo、本轮成本为 0，脚本/画面/音频均为本地实现。
4. 进入项目脚本页，编辑一个分镜的描述或旁白；用键盘导航项目卡片，展示保存检查点和误操作确认。
5. 展开任务浮层，说明八阶段状态、取消边界、部分成功和“重试当前阶段”入口。
6. 进入预览页播放生成成片，选择导出目录并导出。确认成片库记录、字幕状态和文件路径。
7. 打开设置页，说明 API Key 在桌面版进入系统安全存储，配置导出和备份都不含密钥；Sentry 默认关闭。
8. 收尾说明：当前发布包未签名/公证时仅用于内部验证；公开发布前按 `docs/release-checklist.md` 完成人工签名和干净机器验收。
