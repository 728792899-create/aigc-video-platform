# 已知边界

- 当前是本地 MVP，不是生产级 SaaS。
- 没有账号体系、计费系统、多租户隔离和素材版权审核。
- 一键成片取消在下一个分镜边界生效，以避免截断文件写入；已生成素材会保留，任务标记为 `partial`。
- 服务重启后运行中任务会标记为 `interrupted`，目前不会自动续跑；可从项目工作台使用“继续完成检查”与“只重试失败项”手动恢复。
- Demo 模式用于展示完整流程，不代表真实模型生成质量。
- 视频合成依赖 FFmpeg；缺失时应提示安装或降级为素材预览。
- 公开源码与默认分发包不包含任何内置共享模型密钥；真实生成前需由用户在设置页配置自己的凭证。
- `npm run quality` 不依赖联网审计；生产依赖使用 `npm run security:audit`，包含开发工具链时使用 `npm run security:audit:all`。
- 当前完整审计仍会报告 Vitest 2 内嵌开发服务器的 `esbuild` 公告；它不进入生产包，彻底消除需单独验证 Vitest 4 的破坏性升级，不能用 `audit fix --force` 静默改写工具链。
