# 产品术语与内容规范

本规范用于 Vue、Electron、Figma、测试和文档。界面优先使用创作者能理解的语言；稳定 API、数据库和审计值保持不变，并只在“高级详情”中显示。

## 术语转换

| 技术词 | 默认界面 | 高级详情 |
| --- | --- | --- |
| revision | 版本 | `revision rN` |
| stale | 内容已过期 / 上游版本已变化 | `stale` 与受影响依赖 |
| reconcile | 对账并确认远端结果 | `reconcile`、幂等键、Provider receipt |
| CAS | 检查版本后保存 | expected revision / conflict |
| LKG | 当前可靠版本 | last-known-good revision |
| hash | 内容指纹 | SHA-256 / assembly hash |
| partial | 部分完成 | 成功数、失败数、CandidateBatch ID |
| outcome_unknown | 结果暂时无法确认 | Attempt、correlation ID、receipt |

禁止把“下一步”“继续”“确定”“点击这里”和单独的“重试”作为关键按钮。按钮必须说明对象和结果，例如“前往剧本编辑”“打开任务中心并对账”“仅重试失败候选”“通过预检并开始本地导出”。

## 状态与错误结构

用户反馈依次回答四件事：发生了什么、是否保存、下一步做什么、诊断标识是什么。正文不显示凭证、原文、Prompt、绝对路径、Provider payload 或签名 URL。

```text
标题：候选批次部分完成
说明：8 个候选可审阅，2 个生成失败；成功项已保留。
主操作：仅重试 2 个失败候选
次操作：打开任务诊断
高级详情：CANDIDATE_BATCH_PARTIAL · correlation ID
```

## 数字与格式

- 日期时间：界面使用用户本地时区；审计/API 使用 ISO 8601 UTC。
- 相对时间：一分钟内显示“刚刚”，其余使用“X 分钟/小时/天前”；高级详情保留精确时间。
- 金额：人民币用 `¥0.00`；Provider 原币种必须带 ISO currency。Demo 固定显示“计费 ¥0 / 未产生付费请求”。
- 时长：小于一分钟用秒，时间线用 `mm:ss.mmm`，内部保持毫秒整数。
- 数量：使用“镜头、候选、失败项、Attempt”等对象单位，不显示孤立数字。
- 百分比：0–100%，最多一位小数；未知进度显示阶段和已完成项，不伪造百分比。
- Provider：`显示名 / 模型`，并同时显示 Demo/真实、计费验证和降级状态。
- ID/hash：默认显示首 8 位与末 4 位；复制完整值必须是明确操作。

## 空状态与弱网

空状态必须包含原因、一个主操作、帮助入口和诊断入口（若可诊断）。搜索无结果保留筛选条件，并提供“清除筛选”；加载失败不伪装为空数据。媒体缺失时保留原有尺寸与元数据区，显示替换/重新定位/诊断动作，避免布局跳跃。

## 内容来源与排序

- Workspace 完成状态来自当前项目 canonical snapshot，前端不另存进度。
- 项目列表默认按 `updatedAt` 倒序；任务按 `updatedAt` 倒序；领域对象使用服务端 ordinal/图投影顺序。
- Provider 任务状态通过 Socket.IO 增量更新，用户主动刷新会读取服务端事实。
- 引导状态与开发预览记录是本地用户偏好，不进入项目包、备份或 Provider 请求。
