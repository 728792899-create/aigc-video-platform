# 技术说明

## 一句话

这是一个本地优先的 AIGC 短视频创作 MVP，把短视频生成拆成脚本、分镜、素材、配音、字幕和合成几个阶段，重点解决 AIGC 链路容易失败、需要局部重试和中间结果可编辑的问题。

## 核心设计

- 分阶段工作流：每一步有明确状态，失败后可以保留半成品。
- Provider 抽象：文案、图片、配音、视频阶段可接不同模型，并支持降级。
- Demo 模式：无真实 API Key 时也能走通脚本、分镜、素材占位、配音占位和预览流程。
- 资产闭环：分镜、图片、音频、字幕、视频合成结果都有结构化记录。

## 后续方向

- 任务队列与并发控制。
- 生成记录持久化与失败恢复。
- 素材版权与内容安全治理。
- 长视频分章节生成、分段合成和最终拼接。
